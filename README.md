# 🍕 飲食店向けWebサイト制作デモ集

## 📋 概要

飲食店向けのWebサイト制作サービスを営業するためのデモサイト集です。
実際の機能は実装されていませんが、デザインとレイアウトの提案としてご利用いただけます。

## ✨ 含まれるデモサイト

### **1. ☕ カフェ・セレニティ**
- **ファイル**: `cafe-serenity/`
- **特徴**: 落ち着いた雰囲気のカフェサイト
- **機能**: ヒーローセクション、メニュー、店舗情報
- **レスポンシブ**: 完全対応（スマホ・タブレット・PC）

### **2. 📅 予約システムデモ**
- **ファイル**: `reservation-demo/`
- **特徴**: 多段階フォームの予約システム
- **機能**: ステップインジケーター、時間選択、コース選択
- **レスポンシブ**: 完全対応

### **3. 🍕 オンライン注文・デリバリーシステム**
- **ファイル**: `online-order-demo/`
- **特徴**: 完全な注文フローのデモ
- **機能**: メニュー選択、カート機能、注文フォーム、完了画面
- **レスポンシブ**: 完全対応

## 🚀 使用方法

### **ローカルでの確認**
```bash
# 各サイトのindex.htmlをブラウザで開く
open cafe-serenity/index.html
open reservation-demo/index.html
open online-order-demo/index.html
```

### **Vercelでの公開**
1. このリポジトリをVercelに連携
2. 自動デプロイで公開
3. 各サイトに以下のURLでアクセス可能：
   - カフェサイト: `/cafe-serenity/`
   - 予約システム: `/reservation-demo/`
   - オンライン注文: `/online-order-demo/`

## 🎨 デザインの特徴

### **カラーパレット**
- **カフェ**: ブラウン系（落ち着いた雰囲気）
- **予約システム**: ブルー系（信頼感）
- **オンライン注文**: レッド系（食欲をそそる）

### **レスポンシブ対応**
- **デスクトップ**: 1200px以上
- **タブレット**: 768px - 1024px
- **スマートフォン**: 480px - 768px
- **小型スマートフォン**: 480px以下

### **アニメーション**
- ホバーエフェクト
- スムーススクロール
- フェードイン・スライドイン
- インタラクティブな要素

## 🔧 技術仕様

- **HTML5**: セマンティックマークアップ
- **CSS3**: Flexbox、Grid、アニメーション
- **JavaScript**: ES6+、モジュラー設計
- **レスポンシブ**: メディアクエリ、モバイルファースト
- **アクセシビリティ**: ARIA属性、キーボードナビゲーション
